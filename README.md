# 💫 Sobre mí:
**Desarrollador de Software enfocado en Ingeniería de IA.** Mi especialización técnica se centra en construir aplicaciones escalables donde la IA no es un añadido, sino el núcleo funcional.

Domino el **ciclo completo de desarrollo (End-to-End)**: desde la concepción de arquitecturas Full Stack hasta la integración de **Agentes de IA y flujos RAG** en entornos productivos. Mi formación técnica me permite aplicar patrones de diseño estructurales (MVC, OOP, SOLID) y garantizar la fiabilidad del software mediante **Test-Driven Development (TDD)**.

Como **AI Developer**, mi stack se extiende desde el análisis de datos (EDA, Feature Engineering) hasta el entrenamiento y despliegue de modelos (Deep Learning, NLP, MLOps), priorizando siempre la eficiencia computacional y el valor técnico.
